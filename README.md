# Questionnaire Design

用于设计、制作、预览和验证线上问卷，重点适配问卷星（WJX）。

## 主要功能

- 检查筛选题、渠道分流和结束逻辑；
- 检查线上、门店及双渠道比较题的显示范围；
- 逐题核对逻辑条件，避免批量设置漏题；
- 检查必答、选答和多选题数量限制；
- 在保存或发布前模拟非购买者、仅线上、仅门店、双渠道四条路径；
- 区分草稿保存、预览和正式发布状态。

## 使用原则

先建立题目清单和逻辑矩阵，再进行平台操作。平台操作完成后，必须逐题复核逻辑条件，并重新检查保存后的状态。未通过自检时，不报告“已完成”。

详细规则见 [`SKILL.md`](SKILL.md)。
